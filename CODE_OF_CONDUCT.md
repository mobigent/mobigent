# Code Of Conduct

Mobigent aims to be a welcoming, useful open-source project.

## Expected Behavior

- Be respectful and constructive.
- Assume good intent, but be clear when something is unsafe or incorrect.
- Keep discussions focused on improving the project.
- Help newcomers understand the architecture and tradeoffs.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Publishing private information.
- Dismissing security concerns without investigation.
- Repeatedly derailing technical discussions.

## Enforcement

For now, maintainers may remove comments, close issues, or restrict participation when behavior harms the project. This policy can be replaced with a fuller contributor covenant as the community grows.
